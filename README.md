# Hermes perso — pages publiques

Site statique de présentation du client OAuth personnel Hermes perso.

- Accueil : https://ylark.github.io/hermes-perso-pages/
- Confidentialité : https://ylark.github.io/hermes-perso-pages/confidentialite.html
- Conditions : https://ylark.github.io/hermes-perso-pages/conditions.html

Publication GitHub Pages depuis la racine de la branche main. Aucun outil de compilation ni dépendance externe. Le site ne contient pas de connexion Google : il décrit une installation personnelle séparée.

## Sécurité

Ne jamais ajouter de JSON OAuth, jeton, mot de passe, email, document Google ou journal d’exécution. Ne publier ici que des informations générales. Les demandes de support et le dépôt sont publics.

## Configuration Google

Renseigner les trois URL ci-dessus dans Branding et le domaine `ylark.github.io` dans les domaines autorisés. Si Google demande une preuve de propriété, ajouter la propriété de préfixe d’URL `https://ylark.github.io/hermes-perso-pages/` dans Search Console avec le même compte Google que le projet. Choisir le fichier HTML et le publier à la racine de ce dépôt, puis vérifier l’URL exacte avant validation. Ne pas inventer de fichier ou de valeur de validation.

La publication du site n’est pas une validation de l’application par Google. Les exigences d’utilisation limitée, le statut de publication et la configuration des fournisseurs d’IA restent à vérifier séparément.
